# cleitinho

Framework open-source para criar bots agents de IA personalizáveis.

> 🚧 Projeto em fase inicial. A API, a estrutura e a documentação ainda estão sendo definidas.

## Sobre

O **cleitinho** tem como objetivo facilitar a criação de agentes de IA que você pode adaptar ao seu caso de uso: personalidade, instruções, ferramentas, integrações e canais de comunicação.

## Objetivos

- **Personalizável**: defina comportamento, persona e regras de cada agent.
- **Extensível**: adicione ferramentas e integrações próprias.
- **Agnóstico de modelo**: use o provedor de LLM que preferir.
- **Aberto**: desenvolvido de forma colaborativa pela comunidade.

## Status

O projeto está no início. Ainda não há uma versão utilizável. Acompanhe o repositório para novidades.
